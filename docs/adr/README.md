# Architecture Decision Records (ADR)

このディレクトリはプロジェクトの重要なアーキテクチャ上の決定を記録します。

## ADR とは

ADR（Architecture Decision Record）は「なぜそのアーキテクチャを選んだか」を記録するドキュメントです。
コードを読んでも分からない判断の背景・トレードオフ・却下した代替案を残すことで、
将来の自分やチームメンバーが同じ議論を繰り返さずに済みます。

## ファイル命名規則

```
NNN-kebab-case-title.md
```

- `NNN`: 3桁のゼロ埋め連番（001, 002, ...）
- タイトル: 決定内容を端的に表す kebab-case

## ステータス

| 値 | 意味 |
|---|---|
| 提案中 | 議論中・未確定 |
| 承認済み | 採用・実装済み |
| 廃止 | 別の ADR に置き換えられた |
| 非推奨 | 使用を避けるべきだが削除はしない |
